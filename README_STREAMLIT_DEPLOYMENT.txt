HEALTHAI / HWRPA STREAMLIT DEPLOYMENT

WHAT CHANGED
- The dataset uploader has been removed completely.
- Streamlit loads the trained model bundle generated by your Google Colab notebook.
- The dashboard uses the notebook's four classifiers: Logistic Regression, Decision Tree, Random Forest and SVM.
- It uses the notebook's saved HWRPA weights, feature order and validation-selected threshold.
- It does not retrain the models on every app visit.

IMPORTANT: FILES TO ADD TO THE SAME GITHUB REPOSITORY AS app.py
1. app.py
2. requirements.txt
3. hwrpa_model_bundle.joblib
4. hwrpa_test_metrics.csv
5. validation_model_comparison.csv
6. feature_importance.csv

HOW TO EXPORT THE FILES FROM GOOGLE COLAB
Your notebook's Cell 31 already creates these files in /content:
- hwrpa_model_bundle.joblib
- hwrpa_test_metrics.csv
- validation_model_comparison.csv
- feature_importance.csv

After Cell 31 finishes, run this in a new Colab cell to download each artifact:

from google.colab import files
for name in [
    "hwrpa_model_bundle.joblib",
    "hwrpa_test_metrics.csv",
    "validation_model_comparison.csv",
    "feature_importance.csv",
]:
    files.download("/content/" + name)

Then upload all four downloaded files to the SAME GitHub repository/folder that contains app.py.
Do not upload the full raw CDC dataset to Streamlit. It is not needed by this dashboard.

STREAMLIT COMMUNITY CLOUD
1. Push app.py, requirements.txt and the four Colab-generated artifacts to GitHub.
2. In Streamlit Community Cloud, create a new app from that repository.
3. Select app.py as the main file.
4. Deploy. No dataset upload is required.

LOCAL TEST
pip install -r requirements.txt
streamlit run app.py

IMPORTANT
- The .joblib file contains executable Python pickle data. Only load the file generated by your own trusted Colab notebook.
- The notebook's target is CVDCRHD4: self-reported status (1=Yes, 2=No), not future disease prediction.
- This is an academic research demonstration, not a diagnosis or clinically validated risk assessment.
- The app displays actual metrics only when the Colab-generated CSVs are present. It does not invent missing results.
